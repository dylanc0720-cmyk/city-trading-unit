# City Trading Unit

A phone stand-in for the electronic trading unit from a 2009 city-building board game, made for when the original stops working. It is fan-made and not affiliated with Hasbro.

- **Build** spins and lands on 1, 2 or 3 blocks, or a station. Odds can be changed in Settings.
- **Auction** runs a 50-second timer. The last 5 seconds have a warning, and a gavel sounds at the end. A bid tracker logs the top bid and bidder.
- **Deal timer** uses the same timer for trades between players.

## Install on iPhone
1. Open the site in **Safari**.
2. Tap **Share**, then **Add to Home Screen**.
3. Open it from the new icon. It runs full-screen and works offline.

All the sounds are synthesized in the browser, so the app has no audio files.
